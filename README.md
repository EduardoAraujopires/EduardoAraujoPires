📋 Sobre o Projeto
Sistema completo para conectar doadores e receptores de alimentos, combatendo desperdício e promovendo segurança alimentar.

🚀 Funcionalidades
✅ Gestão de Usuários: Doadores e receptores com perfis personalizados

✅ Sistema de Match: Algoritmo inteligente de compatibilidade

✅ Dashboard Admin: Métricas e relatórios em tempo real

✅ API RESTful: Documentada e segura com JWT

✅ Dockerizado: Facilidade de deploy e escalabilidade
